# Predicción de Precio de una Acción

Proyecto de regresión / series de tiempo listo para Google Colab. Incluye EDA, lags, modelos y SHAP.

## Abrir en Google Colab

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/DanyPreisz/precio-accion/blob/main/precio_accion_colab.ipynb)

## Contenido

- Serie de tiempo simulada (tendencia + estacionalidad + ruido)
- Features: lags y media móvil
- EDA (plot de serie, scatters)
- Modelos: Ridge, Random Forest, Gradient Boosting
- Feature importance
- **SHAP** (summary plot)
- Conclusiones

Datos: simulados

Rango esperado (ejemplo): R² > 0.85
